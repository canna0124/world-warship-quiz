世界の軍艦クイズ v1

【内容】
第一次世界大戦ごろから現代までの、
戦艦・巡洋戦艦・大型水上戦闘艦を写真で当てる4択クイズです。

【収録】
試作版として20隻を収録しています。
日本・アメリカ・イギリス・ドイツ・フランス・イタリア・ロシア・中国・韓国など。

【起動方法（Windows）】
このフォルダーを開き、
簡単なローカルWebサーバーから index.html を起動してください。

方法1：Visual Studio Code がある場合
1. フォルダーをVS Codeで開く
2. Live Server拡張機能を入れる
3. index.html を右クリック
4. Open with Live Server

方法2：Pythonが入っている場合
1. このフォルダーでPowerShellを開く
2. 次を実行
   python -m http.server 8000
3. ブラウザで
   http://localhost:8000
   を開く

※ index.html をダブルクリックするだけだと、ブラウザの制限で ships.json の読み込みに失敗する場合があります。

【画像について】
画像はアプリ実行時にWikipedia REST APIから取得します。
各問題画面の「画像・出典」から元ページを開けます。
インターネット接続が必要です。
